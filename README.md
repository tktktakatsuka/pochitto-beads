# ぽちっとビーズ

写真やイラストを読み込んで、アイロンビーズの図案に変換する Web ツールです。

- 横のビーズ数（15〜58）と使う色の数を選んで変換
- 背景ぬき・輪郭線を残す・ディザリング
- 拡大して1マスずつ手直し（ペン・消しゴム・塗りつぶし・スポイト、もどす／やりなおす）
- 記号つき図案と、色ごとに必要な粒数を画像で保存

画像の処理はすべてブラウザの中で行い、どこにも送信しません。

## ファイル

- `src/app.html` … ページ本体
- `src/head.html` … ページの頭の部分（文字コード・言語・スマホ表示の設定など）
- `index.html` … 公開用。`sh build.sh` で上の2つから作る

ビーズの色はおおよその値で、メーカーの実際の色とは少しちがいます。
